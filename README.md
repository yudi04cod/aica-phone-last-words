## What it does

`main.py` writes one line — the funniest farewell a phone could say as its
battery hits 1 percent — to `entry.txt` (in `$MAKEFUN_OUTPUT_DIR`, or
`/output` by default). Pure Python standard library, fully deterministic:
every run writes the exact same line.

## Run it

```sh
python3 main.py
```
